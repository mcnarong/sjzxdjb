必看说明
========

本说明记录桌面监控后台、Web 控制台和命令行里已经做好的功能和使用注意事项。
当前默认入口是桌面监控后台；Web 控制台仍保留为备用。已支持截图校准并保存坐标文件；QQ 账号管理列表会动态识别行位置。


一、启动桌面监控后台
1. 双击项目根目录的 run_gui.bat，或在当前目录运行：python main.py。
2. 如果要打开备用 Web 控制台，双击 run_web.bat，或运行：python main.py web。
3. Web 控制台默认浏览器地址：http://127.0.0.1:8765/。
4. 手机需要提前开启 USB 调试，并在手机上允许调试授权。
5. 建议只连接一台手机，避免脚本操作到错误设备。
6. 旧版 Tkinter 桌面控制台保留为：python main.py tk-gui。


二、基本注意事项
1. “预演”只打印流程，不会真实点击手机。
2. “执行”会真实操作手机，运行前确认手机已连接、屏幕可用。
3. 运行过程中可以点“停止当前任务”中断。
4. 勾选“保留过程截图”后，截图会保存到 captures 文件夹。
5. 如果界面或游戏版本变化，脚本坐标可能点偏。
6. 设备选择在页面顶部，留空时由 ADB 自动选择设备。
7. “停止当前任务”会请求当前正在执行的脚本停止。
8. 定时任务固定为每天 2 个北京时间触发，不再使用间隔小时。
9. 终端日志会同步保存到 log\时间.log；每次启动会先把上一次遗留的 .log 压缩成 log\时间_previous_logs.zip，再创建新的 .log。
10. 真实执行脚本时，每一步都会保存校验截图到 captures\step_checks\时间\；校验失败会报错并停止当前脚本。


三、QQ 切换账号
位置：桌面监控后台“运行操作”区域，或 Web 控制台“执行”区域。

已有功能：
1. 可选择 ADB 设备。
2. 当前只使用 device_profiles\xiaomi_2211133c.txt 里的已验证 QQ 坐标。
3. 可设置 QQ 总账号数 1-8，并动态点击对应的可切换账号行。
4. 可勾选“QQ 过程截图”。
5. 可勾选“预演模式”查看流程。
6. 可点“QQ 切换”真实切换 QQ 账号。
7. 可点“打开账号列表”查看“账号与安全”里的账号管理列表当前画面。

注意事项：
1. QQ 账号选择会动态读取“账号与安全”页的账号管理列表。QQ 总账号数=当前登录账号+可切换账号，脚本点击第“总账号数-1”个可切换账号。
2. QQ 切换路径为：打开 QQ > 点击头像 > 设置 > 账号与安全。
3. 账号选择不识别账号名称，只按配置的 QQ 总账号数决定点击第几个可切换账号；当前登录账号右侧有勾，不参与切换。
4. 如果 QQ 页面布局变化，设置或账号与安全入口坐标可能需要重新校准。
5. 如果打开 QQ 后或切号后弹出“安全提醒”，会点击“取消”。
6. 执行切换结束后，会按当前页面状态返回：已在消息页就直接回桌面；在账号页或设置页才逐层返回；在侧栏时点击右上角 ×。


四、三角洲制作
位置：桌面监控后台“运行操作”区域，或 Web 控制台“三角洲/完整流程配置”和“执行”区域。

已有功能：
1. 可选择 ADB 设备。
2. 当前只使用 device_profiles\xiaomi_2211133c.txt 里的已验证三角洲坐标。
3. 制作台默认全选。
4. 可手动勾选或取消制作台。
5. 可选择是否从启动游戏开始。
6. 可选择执行后是否退出游戏。
7. 可选择退出前是否退出登录。
8. 可开启自动检查/领取。
9. 可选择材料不足时是否一键补齐，默认勾选。
10. 可保留过程截图。
11. 点击开始游戏后会检查是否出现活动弹窗，检测到才点击右上角 X；检测到或未检测到都会写入终端日志。
12. 真实执行时会在每次点击、启动和按键前截图，并等待画面稳定后再操作；登录页/开始游戏前的动态 CG 段会跳过稳定帧等待，只检查截图有效、未锁屏和非黑屏。


执行逻辑：
1. 从启动游戏开始时，点击开始游戏后先截图检查活动弹窗。
2. 如果检测到活动弹窗，会点击右上角 X，等待间隔后再进入特勤处。
3. 如果没有检测到活动弹窗，会在日志提示未检测到，等待间隔后直接进入特勤处。
4. 脚本进入特勤处后，逐个检查已勾选制作台。
5. 如果制作台显示可领取，会先领取并截图复查两次。
6. 如果制作台正在生产，会二次确认后跳过。
7. 如果制作台空闲，会进入制作详情并选择第一个制作项。
8. 进入详情后会检查材料。
9. 如果任意材料数量显示红色不足，比如 0/1、1/2，会判定材料不足。
10. 未勾选“一键补齐”时，材料不足会跳过，不会强行生产。
11. 勾选“一键补齐”时，材料不足会尝试补齐后继续生产。
12. 材料足够时才会点击生产，并在返回特勤处后复查是否进入生产中。
13. 所有勾选制作台首轮处理完成后，会整体复查一次；发现空闲或可领取会再处理一次。


五、完整流程
位置：桌面监控后台“运行操作”区域，或 Web 控制台“三角洲/完整流程配置”和“执行”区域。

已有功能：
1. 可选择 ADB 设备。
2. 默认执行 5 轮。
3. 可在完整流程页勾选制作台，默认全选。
4. 可在完整流程页勾选三角洲选项，默认全选。
5. 每轮先执行当前“三角洲”页配置。
6. 三角洲结束回桌面后，按 QQ 总账号数执行 QQ 切换。
7. QQ 切换结束回桌面后进入下一轮。
8. QQ 总账号数支持 1-8；要让所有账号都跑一遍，完整流程轮数通常设成 QQ 总账号数。
9. 新桌面监控后台可以直接输入定时时间并点“启动定时”；保持 GUI 不关闭即可按时间自动运行。

注意事项：
1. 执行前确认桌面监控后台或 Web 控制台勾选“从启动游戏开始”、“执行后退出游戏”和“退出前先退出登录”。
2. 真实执行会按当前界面的“自动检查/领取”设置运行。
3. 预演只打印固定步骤，不会执行智能截图判断。


六、截图说明
过程截图默认保存到：
captures\

常见截图：
1. QQ 切换截图：captures\qq_switch_*.png
2. 三角洲流程截图：captures\gui_production_*.png
3. 三角洲制作台检查截图：captures\gui_check_*.png
4. 三角洲材料详情截图：captures\gui_detail_*.png
5. 每步执行校验截图：captures\step_checks\时间\step_*.png

如果脚本行为异常，先看最新截图，确认手机画面是否和脚本预期一致。


七、当前限制
1. 已支持截图点选校准并保存到 device_profiles\*.txt；不同手机仍需要人工按提示在截图上点一次关键位置。
2. QQ 账号切换不识别账号名称，只按 QQ 总账号数点击对应的可切换账号行。
3. 三角洲制作默认选择第一个制作项。
4. 材料检测依赖当前游戏 UI 的红色数量显示。
5. 如果 QQ 页面或游戏页面布局大改，可能需要重新校准或补新的识别逻辑。


八、发给别人使用
1. 在本机运行 powershell -ExecutionPolicy Bypass -File .\build_portable.ps1 生成便携版。
2. 如果提示没有 PyInstaller，先运行 python -m pip install pyinstaller。
3. 把 dist\ADBAutomation 整个目录压缩发给别人。
4. 对方解压后先运行 00-device-check.bat，自检通过后再运行 01-start-gui.bat。
5. 小米13已保存到 device_profiles\xiaomi_2211133c.txt。新手机点不准时，优先使用截图校准：选择页面阶段，确认手机已经在该页面后让程序截图并自动分析坐标；如果页面不对，先按提示切换页面；自动分析失败时再用手动点选兜底。保存后会生成该手机的 txt 坐标文件。命令行备用方案是 python main.py calibrate-profile qq --key my_phone --label "我的手机 QQ" 和 python main.py calibrate-profile delta_force --key my_phone --label "我的手机三角洲"。
